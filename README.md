# 🎉 Group Welcome · 入群欢迎插件

> 适用于 AstrBot 的入群欢迎插件，支持在设置界面按群配置固定欢迎词、AI 欢迎提示词和欢迎表情包。


---

## 依赖说明

- 本插件**仅验证过支持 OneBot 11 协议**。
- 建议使用 AstrBot v4.12.0 或以上版本。
- 若机器人启动后欢迎未触发，请尝试**重启机器人**或**重载插件**。

---

## 功能特性

- **后台按群配置**：无需在群里输入命令，直接在插件设置页为不同群设置欢迎内容。
- **两种欢迎模式**：可选择直接发送固定欢迎词，或使用固定 AI 提示词生成完整欢迎词。
- **每群独立覆盖**：每个群可单独覆盖欢迎模式、固定欢迎词、AI 提示词和图片开关。
- **欢迎表情包**：可在设置界面上传多张图片，每次欢迎时随机发送。
- **群人数统计**：欢迎语中可追加"你是当前群里第 X 位成员"。
- **私聊发送群规**：新人入群后尝试私聊发送群规内容（默认关闭，防风控）。
- **黑白名单**：灵活控制哪些群启用欢迎功能。
- **防刷屏冷却**：同一用户短时间内重复入群不重复触发。
- **冷却数据持久化**：重启后冷却记录不丢失。

---

## 安装

将插件文件夹（含 `main.py`、`_conf_schema.json`、`metadata.yaml`）放入 AstrBot 的 `data/plugins/` 目录，重启 AstrBot 即可。

## 后台配置（WebUI）

进入 AstrBot 后台 → 插件配置页面，可设置以下项目：

| 配置项 | 说明 | 默认值 |
|:--|:--|:--|
| 🎉 全局默认欢迎语 | 支持变量 `{name}`（昵称）、`{count_text}`（第几位成员） | 内置默认语 |
| 💬 默认欢迎模式 | `text` 为固定欢迎词，`ai` 为固定 AI 提示词 | `text` |
| 📊 开启群人数统计 | 欢迎语末尾追加成员序号 | 开启 |
| 📩 开启私聊群规 | 新人入群后尝试私聊发送群规 | 关闭 |
| 📜 群规内容 | 私聊发送的具体文字 | 内置示例 |
| 🧠 AI 模型提供商 | 指定用于生成欢迎语的模型，留空使用系统默认 | 空（系统默认） |
| 📝 默认 AI 提示词 | 支持 `{name}`、`{group_id}`、`{count_text}` | 内置提示词 |
| 🖼️ 默认发送欢迎表情包 | 是否从上传池随机发送图片 | 关闭 |
| 📁 欢迎表情包上传池 | 在设置页上传 PNG/JPG/GIF/WebP/BMP 图片 | 空 |
| 🏘️ 每群欢迎配置 | JSON 格式的每群覆盖配置，见下方示例 | `{}` |
| ⏱️ 防刷屏冷却（秒） | 同一用户重复入群的最小触发间隔 | 300 秒 |
| ✅ 白名单群号 | 每行一个群号，填写后只有这些群触发欢迎 | 空 |
| 🚫 黑名单群号 | 每行一个群号，白名单为空时生效 | 空 |

### 每群欢迎配置示例

在设置页的「🏘️ 每群欢迎配置」中直接填写：

```json
{
  "123456789": {
    "mode": "text",
    "welcome_template": "欢迎 {name} 加入一群！{count_text}",
    "send_image": true
  },
  "987654321": {
    "mode": "ai",
    "ai_prompt": "你是二群的活泼管理员，请用一句话欢迎新成员 {name}。",
    "send_image": true,
    "images": ["welcome-cat.gif", "welcome-dog.png"]
  }
}
```

- `mode`：`text` 表示固定欢迎词；`ai` 表示固定 AI 提示词。
- `welcome_template`：支持 `{name}`、`{count_text}`。
- `ai_prompt`：支持 `{name}`、`{group_id}`、`{count_text}`。
- `send_image`：是否为该群发送欢迎表情包。
- `images`：可选。填写已上传图片的文件名，只在这些图片中随机；不填则使用整个上传池。
- 未写出的字段自动继承全局默认设置。
- 旧格式 `{"群号": "欢迎词"}` 仍然兼容。

## 指令列表

设置界面已经覆盖全部主要功能，以下命令仅为兼容旧版和临时管理保留。所有指令需要**管理员权限**。

### 欢迎语设置

| 场景 | 指令 | 说明 |
|:--|:--|:--|
| 群聊 | `/welcome set 欢迎 {name} 加入！` | 设置本群专属欢迎语 |
| 群聊 | `/welcome set reset` | 清除本群设置，恢复全局默认 |
| 群聊 | `/welcome set show` | 查看本群当前欢迎语 |
| 私聊 | `/welcome set <群号> 欢迎 {name} 加入！` | 为指定群设置欢迎语 |
| 私聊 | `/welcome set reset <群号>` | 清除指定群设置 |
| 私聊 | `/welcome set show <群号>` | 查看指定群当前欢迎语 |

### 状态查询

| 指令 | 说明 |
|:--|:--|
| `/welcome status`（群聊） | 查看插件状态 + 本群欢迎语及来源 |
| `/welcome status`（私聊） | 查看插件状态 + 已自定义群的数量 |
| `/welcome status <群号>`（私聊） | 查看插件状态 + 指定群欢迎语 |

### 功能开关

| 指令 | 说明 |
|:--|:--|
| `/welcome count on/off` | 开启 / 关闭群人数统计 |
| `/welcome rules on/off` | 开启 / 关闭私聊群规 |
| `/welcome ai on/off` | 开启 / 关闭 AI 个性化欢迎 |

### 黑白名单

白名单不为空时，只有白名单内的群会触发欢迎；白名单为空时，黑名单内的群不触发欢迎。

| 指令 | 说明 |
|:--|:--|
| `/welcome wl add <群号>` | 加入白名单 |
| `/welcome wl del <群号>` | 移出白名单 |
| `/welcome wl list` | 查看白名单 |
| `/welcome bl add <群号>` | 加入黑名单 |
| `/welcome bl del <群号>` | 移出黑名单 |
| `/welcome bl list` | 查看黑名单 |

## 常见问题

**Q：开启了私聊群规，但新人没收到私聊？**

新成员可能关闭了"允许陌生人发起临时会话"，或当前平台风控限制了临时会话。建议将重要群规直接写在群欢迎语中。

**Q：AI 欢迎模式没有生效？**

请确认：①「默认欢迎模式」或对应群的 `mode` 已设为 `ai`；② AstrBot 已配置可用的大模型；③ 若指定了模型，确认模型 ID 填写正确。AI 调用失败时插件会自动回退到固定欢迎词，避免新人收不到欢迎消息。

**Q：图片已经上传，为什么没有发送？**

请确认全局「默认发送欢迎表情包」已开启，或对应群的 `send_image` 已设为 `true`。如果配置了 `images`，其中的文件名必须与上传池里的文件名一致。

## AI 功能使用声明

启用"AI 个性化欢迎"功能即表示您同意以下条款：

1. **数据传输**：本插件仅将新成员的**公开昵称**发送给您配置的大语言模型，不涉及 QQ 号或其他私密信息。
2. **内容免责**：AI 生成内容由您所配置的模型提供，插件开发者不对内容的准确性或适宜性作任何保证。
3. **费用说明**：启用此功能将消耗您配置的模型服务的 API 调用额度，请根据实际需求酌情使用。
